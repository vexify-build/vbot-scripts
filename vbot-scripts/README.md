## 🎱 dev8ball — 技术选型纠结终结者

```bash
npx degit vexify-build/vbot-scripts/bin/dev8ball.js

```

## 🧛 excuse — 程序员甩锅专用

```bash
node bin/excuse.js          # 随机甩锅
excuse bug                  # 甩锅给 bug
excuse deploy               # 甩锅给部署
excuse meeting              # 甩锅给会议
excuse boss                 # 甩锅给老板
excuse chaos                # 甩锅给混沌
node bin/excuse.js --list   # 查看全部
```
