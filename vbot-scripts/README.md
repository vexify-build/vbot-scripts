# 🎱 dev8ball

> 技术选型纠结终结者 — 专治「该用哪个框架/语言/方案」的世纪难题

## 安装

```bash
npm install -g vexify-build/vbot-scripts
# 或者直接跑：
npx dev8ball "你的技术问题"
```

## 使用

```bash
# 直接问
dev8ball "该用 TypeScript 还是 Go？"

# 查看所有答案类型
dev8ball --list
```

## 效果

```
🎱 Dev8Ball 正在思考你的问题...

   "该用 Rust 还是 Go?"

   ────────────────────────────────────────
   🔥 这个栈会烧穿你的时间
   ────────────────────────────────────────
```

## 答案分级

- 🔴 **强力 Yes** — 无脑冲
- 🟡 **Yes** — 合理，可以试
- 🟣 **不确定** — 命运在迷雾中
- 🟠 **No** — 三思而后行
- 🔴 **强力 No** — 埋了吧
